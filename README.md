# Carol Magno Arquitetura

Projeto estatico criado a partir do template `projects/templates/arch_site`, usando o conteudo textual e imagens publicas do site atual da Carol Magno Arquitetura.

## Paginas

- `index.html`: home institucional com apresentacao, portfolio destacado e premissas sustentaveis.
- `sustentabilidade.html`: conteudo de certificacoes ambientais.
- `portfolio.html`: galerias por categoria com imagem de destaque, grade lateral e carrossel em primeiro plano.
- `viabilidade.html`: apresentacao da viabilidade arquitetonica.

## Assets

As imagens ficam em `assets/carol/` com nomes simplificados para facilitar troca e manutencao.

## Visual

A distribuicao usa a estrutura do template de arquitetura, mas a marca, textos, redes e imagens seguem o site da cliente.
